关于本页

它做什么：接收一批平台运营数据，由三位专家串行处理——① 数据采集员清洗指标、标注可用性；② 业务判断员按四条规则出校准动作卡；③ 质量复核员逐项复核并给出最终卡片表。上一个的产出交下一个，团长（质量复核员）不通过则退回重跑一次，仍不通过如实报不通过。

四条判定规则：R1 互动率低于 0.02（优先级 1）；R2 粉丝少于 100（优先级 2）；R3 曝光大于 0 且点赞等于 0（优先级 2）；R4 全局兜底——仅当所有平台累计 0 卡时补 1 张（优先级 3）。同一平台可同时命中多条，逐条出卡不合并。

关键口径：互动率 =（点赞+评论）÷ 曝光，曝光为 0 记 0 不除零；阈值判定用未舍入的原始值，四舍五入仅用于展示；缺字段标「未获取」不补零；取数失败的平台只进数据可用性、不出卡。
